# review-class

This repository contains the `review-class` agent skill. It guides an agent from lecture-source acquisition through flexible lesson planning, chapter writing, and Markdown, HTML, DOCX, or PDF export.

The skill is at [.agents/skills/review-class/SKILL.md](.agents/skills/review-class/SKILL.md). Its instructions are intentionally progressive: source the transcript first, devise the outline second, write the lesson third, and export last.

Modal transcription is preferred. The skill includes deployable Parakeet and WhisperX scripts in [.agents/skills/review-class/scripts](.agents/skills/review-class/scripts) and a Pandoc/Typst template in [.agents/skills/review-class/assets](.agents/skills/review-class/assets).
