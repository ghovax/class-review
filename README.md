# review-class

This repository contains the `review-class` agent skill. It guides an agent from lecture-source acquisition through flexible lesson planning, chapter writing, and Markdown, HTML, DOCX, or PDF export.

The `review-class` skill is the repository entry point. Its instructions are intentionally progressive: source the transcript first, devise the outline second, write the lesson third, and export last.

Modal transcription is preferred. The skill includes deployable Parakeet and WhisperX scripts, plus a Pandoc/Typst template and matching export styles.
